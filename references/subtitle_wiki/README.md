# Subtitle reference notes 字幕规范查询

Original, compact reference notes for Chinese, English, Japanese and Korean. These pages summarize a few practical distinctions and point to authoritative sources; they do not reproduce platform manuals, supply every exception or guarantee compliance.

First identify the target language/region, ordinary subtitles versus SDH/CC, audience and title-specific delivery instructions. Then obtain the recipient's current guide. Do not apply English counting or punctuation rules to another language.

Official lookup: [language/localization directory](https://videocentral.amazon.com/support/delivery-experience/mec-title-meta-data/languages-and-genres), [general subtitling principles](https://videocentral.amazon.com/support/delivery-specifications/prime-video-subtitling-guidelines?language=en_US).

These notes were prepared from previously reviewed 2026 reference material; the current official version was not re-checked online during public packaging. Platform guide text and original format schemas are not included. References are not a program-wide promise that all listed rules are implemented.
