# English reference notes

[Reference index](README.md) · [Implementation status](implementation.md)

Check US/UK spelling, audience and whether the deliverable is ordinary translation, SDH or CC. Dialogue, lyrics, speaker IDs and meaningful sound descriptions have different editorial roles. A visible action is not proof that a sound occurred; an off-screen speaker is not automatically a voiceover.

Previously reviewed English language guidance uses a 42-character, two-line baseline and different adult/children reading speeds. Confirm the current guide, character-count definition, timing and exceptions for the actual recipient. Do not import CC limits into an SDH delivery.

The application's normal/SDH profile and bilingual profile differ. A bilingual project's 17 CPS target/21 CPS ceiling is an explicit workflow policy, not a universal children's specification. Estimated syllables are advisory. Grammar-aware breaks, reveals, numbers, punctuation, songs and sound-caption necessity still need language and audiovisual judgment.

Use the official sources linked from the index before delivery. No official guide copy, certification or exhaustive ruleset is supplied here.
