# SoloPup Subtitle Studio 2.0.0-rc.5

Developed by SoloPup. Core strengths: SDH accessibility captions and English subtitles for Chinese audio.

Public preview candidate · 2026-10-28. This is a public preview release. Download assets and publication status are available on GitHub Releases.

- Shared project entry for ordinary subtitles/SDH and Chinese-audio/English-subtitle localization.
- Parallel source/translation review, screen-aligned bilingual import, estimated syllable differences and separate language exports.
- Local project history, background drafts, explicit save/version conflict protection and ITT/SRT output.
- Original Chinese/English/Japanese/Korean reference summaries with official lookup links and implementation status.
- Public isolation: no private productions, character lists, song assets, project-specific vocalization rules, original platform manuals/schemas, credentials or production databases. Tests use synthetic data.

Limits: English US/UK automatic target interfaces; other language references do not establish production support. macOS local testing does not prove all-platform acceptance. Model/account access needs the user's own configuration. No platform certification or final language approval is implied. See README.md and README.zh-CN.md for the product description; see VALIDATION.md for the verified candidate checks.

## 中文版本说明

由 SoloPup 开发。两大核心亮点：SDH 无障碍字幕，以及保留中文配音的英文字幕本地化。

本版将普通字幕/SDH与中文配音英译接入统一工作台，支持逐屏双语校对、独立导出和本地审核历史。公开版已移除具体节目的资料与专用规则，改用通用证据流程和显式项目配置；四语言规范仅提供原创摘要与官方入口。

这是公开预览候选版；下载文件和发布状态以 GitHub Releases 页面为准。自动目标语言、平台/模型权限及语言质量的边界以产品说明与验证记录为准。
