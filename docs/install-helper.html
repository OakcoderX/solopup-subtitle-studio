Prepare your first local session.

Choose your operating system and copy one consistent set of commands. Nothing runs from this page. / 按系统生成一致的安装命令，本页不会执行命令。

  1. Download and extract the application Public.zip.
  2. Install Python 3.9+ (3.11+ recommended) and FFmpeg/ffprobe separately.
  3. Open your terminal in the extracted folder containing bootstrap.py. On Windows, use PowerShell.

The first command installs project dependencies from the package configuration using the internet. Review the commands before running them. None calls a paid AI provider. The demo generated by these commands is silent.

What success looks like

  1. doctor.py reports Python supported, FFmpeg/ffprobe found and no missing core files. Missing optional Qwen credentials does not block local review.
  2. The final server command keeps running. Open http://127.0.0.1:8877/projects; keep that terminal open.
  3. Use the English control key if you cannot read the Chinese project controls.

For “command not found”, missing media or startup problems, use the existing troubleshooting guide. Windows and Linux commands are provided for inspection; equivalent manual acceptance has not been completed. Use the browser sample instead if you do not want to install software.
