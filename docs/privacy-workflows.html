Know which step uses a provider.

“Runs locally” describes the workspace. It does not make cloud AI processing on-device.

PathWhat happensWhat to prepare
Existing-video + paired-SRT reviewThe local workspace reads your selected local media and subtitle files.No AI account required. Preserve backups.
Optional local ASRA separately installed local model processes audio after dependencies and model weights are downloaded.Initial network download, disk space and compatible dependencies.
Configured cloud productionRequired audio, images, references or text for that task are sent to the provider you configure.Your own account, suitable access, consent and a budget.

Practical boundaries

  • Enter provider keys yourself in local settings. Do not post them in chat or Issues.
  • Saving configuration makes no model request and proves no quota or permissions.
  • Do not expose the trusted local-user application as a public multi-user service.
  • Use synthetic or releasable examples when requesting support.

The browser helpers in this resource hub perform no uploads or model calls. Their source is in the public repository; no analytics or persistent input storage is added.
