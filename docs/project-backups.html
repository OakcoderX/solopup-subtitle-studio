A subtitle export is only part of the project.

Keep the work needed to understand and revise that file after a move.

Preserve the connected set

SoloPup stores local project and review work under Subtitle_Library/ and Subtitle_Projects/. Linked source media is also necessary. An exported SRT or ITT cannot reconstruct every edit, pending question or review decision. Back up the libraries and linked media together, and retain an untouched source copy.

Before moving computers

  1. Save the current work and note the application version.
  2. Record the exact video master and current subtitle revision.
  3. Copy the project libraries, histories and media to your chosen backup destination.
  4. Compare the file inventory and open a disposable copy to check the result.

After reopening

A saved project may still refer to its old media location. Reconnect the correct master when needed and replay known points. A similarly named video is not sufficient evidence of the same edit. Do not treat a successful file copy or a readable subtitle export as proof that media paths and review history survived.

The Backup worksheet separates copy verification from reopening verification. Keep both pending until you have actually checked them. This guide does not run a backup or read any of your local folders.
