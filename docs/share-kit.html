English description

SoloPup Subtitle Studio is an MIT-licensed local workspace for SDH caption review and English subtitles for Chinese audio. Existing paired-SRT review needs no AI account; optional cloud processing uses your own provider and may incur charges. Version 2.0.0-rc.5 is a public preview.

中文介绍

SoloPup Subtitle Studio 是采用 MIT 许可的本地字幕工作台，支持 SDH 无障碍字幕审校及中文配音逐屏英译。已有中英 SRT 可不配置 AI 接口进行审校；可选云端处理需自己的服务商账户，可能收费。当前为 v2.0.0-rc.5 公开预览版。
