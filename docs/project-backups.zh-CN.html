换电脑后仍能理解和修改这份文件，需要保留与它连接的工作资料。

保留完整关联

工作台把本地项目和审核工作保存在 Subtitle_Library/ 与 Subtitle_Projects/，同时还需要引用的原始媒体。单独一份 SRT 或 ITT 不能还原所有修改、待定问题和审核决定。库、历史及关联媒体应一起备份，并保留未改动的源文件。

移动前

  1. 先保存当前工作，记录软件版本。
  2. 写明具体视频母本和字幕修订号。
  3. 将项目库、历史及媒体复制到你选定的备份位置。
  4. 比较文件清单，再用单独副本实际打开一次。

重新打开后

项目可能仍引用旧位置，需要重新关联正确母本，并回放已知片段。文件名相近不代表剪辑版本相同。复制成功、导出文件可读，也不证明媒体路径和审核历史已完整恢复。

Backup 模板把复制验证与重新打开验证分开记录。没有实际检查前，两项都应保持待定。本页不会替你运行备份，也不会读取本机文件夹。
