费用、隐私与支持范围 FAQ

分清哪些工作在本机完成、哪些需要服务商，以及预览版实际验证过的范围。

下载 rc.5 预览版用已有字幕试用

软件免费吗？

代码及原创通用文档采用 MIT 许可。本地校对已有字幕不需要 AI 订阅或账号。云端识别、翻译与复核使用你自己的服务商账号，可能产生费用。适用试用额度由服务商决定；SoloPup 不发放 Key，也不赠送额度。

视频会离开我的电脑吗？

不运行云端处理的校对流程将内容留在本机。主动运行云端任务时，任务所需的音频、图片、剧本参考或文字会发给你配置的服务商。保存接口设置不会调用模型。本地识别需要另装依赖并下载模型。

API Key 怎样保存？

由你在本机设置中自行输入。Key 在本地以明文保存，并在支持的系统上设置仅所有者可读写权限，不是系统钥匙串；不会进入浏览器存储、Git 或发布包。不要发到聊天、Issue 或命令参数中。已配置 Key 不代表模型权限、余额、试用资格或付费能力已验证。

能导出哪些格式？

支持分轨导出 SRT 与 ITT。双语输出沿用原视频文件名，加 .zh 和 .en 语言后缀。交付前需核对收件方当前的节目与语言要求，并检查导出文件。选择规范配置不等于获得平台认证。

支持哪些语言和系统？

自动生产目标为英语 US/UK，包括中文配音配英文字幕。中、英、日、韩四语言 Markdown 规范可供查阅，但日文、韩文自动生产尚未验证。双语编辑页使用中文控件。运行需要 Python 3.9+、FFmpeg/ffprobe 和现代浏览器。macOS 已在本机验证；Windows/Linux 尚未完成同等级人工验收。

音节匹配等于配音或口型同步吗？

不等于。长度与节奏接近是翻译审校目标，音节估算只供参考。系统保留中文音轨，不承诺精确口型同步或音节完全相等；含义准确、信息顺序和英文自然度仍是必要条件。

这是稳定版或认证交付工具吗？

2.0.0-rc.5 是公开预览版。听辨、翻译、校时与 SDH 质量均需人工音画审校；软件和格式检查不能代替最终验收。首次发布未运行远程测试 CI，配置模板位于 docs/ci/。当前适合可信本机用户，不是可直接开放到互联网的多人服务。
