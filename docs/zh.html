SDH 无障碍字幕

除了对白，逐条判断说话人、关键音效、音乐与声音表现，把影响理解的声音写进字幕。普通字幕与 SDH 独立分轨。

保留中文配音，逐屏英译

同屏校对中文与英文，让译文跟随中文断句和信息出现顺序。分语言导出，沿用原视频文件名。

查看中英校对示例

先用已有字幕体验

  1. 下载发布页中的 Public.zip，解压后按 README 安装。
  2. 准备本机视频；中英双语导入需要屏数和时码对应的两份 SRT。
  3. 打开项目页，选择工作方式，逐条回看、修改和保存，再分别导出。

本地播放、导入与人工审校无需 AI 账号。云端识别和翻译需自己的服务商账户，可能产生费用。

使用前了解

需要 Python 3.9+、FFmpeg 和现代浏览器。macOS 已在本机验证，Windows/Linux 尚未完成同等级人工验收。中英编辑页操作项为中文；音节估算辅助审校，不保证口型同步。预览版输出仍需人工音画复核。
