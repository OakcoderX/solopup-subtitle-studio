Before you try SoloPup.

Is it free?

The code is MIT licensed. Local review of existing subtitle files requires no AI account or subscription. Optional cloud AI uses your own provider account and may incur charges; quota and access depend on that provider.

Does my video leave my computer?

Local review without cloud processing keeps the content local. Cloud tasks send the audio, images, references or text required by that task to the provider you configure. Provider configuration alone makes no model request.

Which subtitle formats can I export?

SRT and ITT, as separate tracks. Bilingual exports use language suffixes and preserve the original video filename. Confirm the recipient’s current delivery requirements and review the exported file.

Can I review Chinese audio with English subtitles?

Yes. Import matching Chinese/English SRT screens and timings for offline review. Automatic draft production is optional. English US/UK targets are currently supported; Japanese/Korean reference documents are not verified production support.

Does it run on my computer?

Requirements are Python 3.9+, FFmpeg/ffprobe and a modern browser. macOS has been tested locally. Windows/Linux instructions are provided, but equivalent manual acceptance is incomplete. The bilingual controls currently use Chinese.

Is this a final release or certified delivery tool?

No. Version 2.0.0-rc.5 is a public preview candidate. Human translation, timing and accessibility review remain necessary. Syllable estimates are advisory. A passing local check does not mean platform approval.

Where should I send feedback?

Use GitHub Issues. Include the version, OS, expected behavior, actual behavior and a small synthetic reproduction. Do not attach credentials, unreleased video, private screenplays or customer history.
