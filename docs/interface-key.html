One safe first route

  1. Open http://127.0.0.1:8877/projects.
  2. Choose 新建项目, then the Chinese-audio bilingual workflow.
  3. Use 添加剧集 with a video and matching Chinese and English SRTs. This path needs no AI key.
  4. Review one cue, use 保存 ⌘S, then 导出字幕.
