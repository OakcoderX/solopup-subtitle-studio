Get the local review loop working first.

Installation troubleshooting should not require a paid AI request.

“FFmpeg or ffprobe missing”

Install FFmpeg from its official distribution instructions for your operating system and restart the terminal. Run .venv/bin/python scripts/doctor.py --json in the extracted folder. Check both tool paths.

“Python dependency missing”

Use the virtual environment made by python3 bootstrap.py --install. Confirm Python 3.9+; 3.11+ is recommended. On Windows, use .venv\Scripts\python.exe. The same manual acceptance pass has not been completed on Windows/Linux.

“The local page will not open”

Keep the startup terminal running and use the exact local port it reports. The documented example uses http://127.0.0.1:8877/projects. If that port is already used by a workbench, inspect or reuse that instance rather than overwriting a project.

“The Chinese/English import is rejected”

Check cue count and timestamps with the paired SRT checker. Do not force mismatched files through as different track types. Fix against the source and retain originals.

“Saved project cannot find the video”

Linked local paths may have moved. Restore or reconnect the correct master, then check timing. Back up the project libraries, histories and linked media together.

“No Qwen key”

A key is unnecessary for the paired-SRT manual review path. Cloud production needs a separately configured provider and may cost money. Saving settings alone does not test access.

If still blocked, submit a reproducible problem with OS, version and synthetic example. Exclude secrets, private media, absolute private paths and raw provider payloads.
