Check a cue before asking viewers to read it. / 输入一屏字幕，查看每秒字符数。

This tool runs in your browser. It has no upload form, analytics, storage or cloud AI calls. Input is processed only in this page and is not saved by this tool.

What this number means

This helper counts Unicode code points, including spaces and punctuation, excluding line breaks. Markup is counted literally. It is an editorial estimate; delivery profiles may count characters differently. The starting threshold of 17 is an example, not a universal platform or children’s-content rule. Shorter wording still needs meaning and timing review.
