# Public release checklist

This is a clean public source snapshot. It is separate from any private production workspace or editing library. Do not add original media, private scripts, provider keys/responses, review histories or third-party manuals to this repository.

Before making a GitHub release, run the local Python/JavaScript tests, generate the synthetic demo, check the package manifest and inspect the source inventory. Use a new public Git history if importing from an internal workspace. Choose the destination repository, license, tag and preview/stable status explicitly before uploading.

Local tests are evidence about the checked version. GitHub CI must actually run before reporting its results. A release tag is not platform certification or permission to redistribute third-party material.
