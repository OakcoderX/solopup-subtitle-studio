# 版本说明：2.0.0-rc.5

[English](RELEASE_NOTES.md) · [中文](RELEASE_NOTES.zh-CN.md)

公开预览版 · 由 SoloPup 开发 · 2026-10-28。当前产品文档提供完整中文与英文版本。

## 两大核心亮点

- SDH 无障碍字幕：普通字幕与 SDH 独立分轨，结合有意义的声音候选、证据和人工判断。
- 中文配音配英文字幕：同一视频中双轨对照，断句对应，辅助检查长度与音节。

## 本预览版包含

- 统一项目入口与本地后台初稿，分别保存工作方式配置。
- 修改历史、明确保存及旧版本覆盖保护。
- 分轨 ITT／SRT 导出；双语文件沿用原视频名称并加语言后缀。
- Qwen 首次使用指引，以及云任务入队前的 Key 配置检查；不自动调用模型测试，也不代开计费。
- 中、英、日、韩原创规范摘要、官方链接与实现边界。

## 验证情况与当前限制

首次发布源码在本机通过 259 项 Python 和 4 项 JavaScript 测试，检查了合成媒体离线导入、保存及导出。这些属于软件检查，不证明语言或无障碍质量。首次发布未运行远程测试 CI，配置模板在 docs/ci/。

自动目标为英语 US/UK。macOS 已在本机验证；Windows/Linux 尚未完成同等级人工验收。双语编辑页使用中文控件。模型权限需自己的账号／Key，输出仍需人工音画审校，不代表平台认证。

## 公开内容与文档更新

发布包排除私人节目、角色库、客户审核历史、密钥、第三方原始规范与 Schema。截图使用合成示例及原创 AI 场景画面。main 分支上的中英文产品页、完整指南和截图说明属于文档更新；原有发行标签及下载压缩包保持不变。
