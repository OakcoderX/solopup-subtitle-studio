Do your two subtitle tracks line up?

Find screen-count and timestamp differences before importing a bilingual project.

This tool runs in your browser. It has no upload form, analytics, storage or cloud AI calls. Input is processed only in this page and is not saved by this tool.

Scope

Checks sequential cue numbers, non-empty cue text, SRT timestamp syntax, positive durations, non-overlapping order, equal screen counts and exact millisecond alignment. Comma or dot milliseconds and CRLF line endings are accepted. It flags unsupported blocks rather than silently discarding them. Does not inspect audio, translation, names or reveal order. Passing this helper is not final production approval.
