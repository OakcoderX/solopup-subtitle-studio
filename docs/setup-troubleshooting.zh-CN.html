提示缺少 FFmpeg 或 ffprobe

按 FFmpeg 官方的系统对应方式安装，然后重新打开终端。在解压目录运行 .venv/bin/python scripts/doctor.py --json，核对两个工具路径。

提示缺少 Python 依赖

先用 python3 bootstrap.py --install 建立环境，再使用其中的 Python。要求 3.9+，建议 3.11+。Windows 对应 .venv\Scripts\python.exe；Windows/Linux 尚未完成同等级人工验收。

本地网页打不开

保持启动终端运行，使用它报告的准确端口。文档示例为 http://127.0.0.1:8877/projects。若已有工作台占用该端口，先确认或复用原实例，不要覆盖已有项目。

中英字幕无法导入

用SRT 配对检查器检查屏数与时间。对照原片修正，保留原文件；不要改成其他轨道类型绕过检查。

项目找不到视频

本地媒体可能移动过。恢复或重新关联正确母本，再检查时码。库、审核历史和引用媒体要一起备份。

没有配置 Qwen Key

已有对应双 SRT 的本地人工审校不需要 Key。云端制作需另行配置模型权限和计费；保存设置并不验证接口或额度。
