Try subtitle review without an AI key.

Use the included synthetic demo to explore the editor before connecting a provider.

1. Download and prepare

Download the Public.zip release asset, extract it and open a terminal in the extracted application folder. Install Python 3.9+ (3.11+ recommended) and FFmpeg/ffprobe first. Initial dependency installation requires internet access.

2. Generate the demo and start

python3 bootstrap.py --install
.venv/bin/python scripts/doctor.py --json
.venv/bin/python scripts/make_demo.py
.venv/bin/python start_workbench.py --video examples/demo/generated/demo.mp4 --standard-srt examples/demo/normal.srt --sdh-srt examples/demo/sdh.srt --port 8877

On Windows use .venv\Scripts\python.exe instead of .venv/bin/python. Windows and Linux have not completed equivalent manual acceptance.

3. Explore locally

Open http://127.0.0.1:8877/projects. The startup may first open the seed editor; “项目与制作” returns to the project page. Keep the terminal running. Review a cue, replay, edit, save and export a track.

The generated video is silent and synthetic. Its subtitle text demonstrates editing controls; it is not a transcription, sound-recognition or accessibility-quality benchmark.

Use your own paired SRT files

Create a Chinese-audio bilingual project and import your video with matching Chinese and English SRT files. This review path does not require cloud processing or an API key. Local ASR needs separate dependencies and model weights; AI translation needs a provider.
